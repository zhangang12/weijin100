微金100 · UI 设计稿整合版

{{VERSION}} · 首页、买家下单、我的、我的订单、货品发布 5 个模块合为一个文件，已同步 2026 年 10 月的合规调整。请业务逐屏确认，有修改意见直接在屏幕上批注。

1为什么调整

平台暂不经手用户资金。目前没有增值电信业务经营许可证，线上不能向用户收钱：取消保证金（充值 / 退款 / 冻结 / 扣款），平台代交接服务费改为线下结算，佣金暂不展示。
规避监管敏感说法。深圳市金融委 2026 年 2 月提示禁止「缴纳保证金锁定黄金价格」类交易。产品定位改为「实物现货信息发布 + 线下实名交货」，「锁价」「交割」「大盘」等说法统一替换。

3本期暂停 / 隐藏的功能

  • 暂停保证金：充值、退款、额度、冻结 / 解冻全部暂停。「我的」⑤ 保证金与额度、⑥ 充值、⑦ 退款三屏保留为灰色「暂停」稿，取得许可证后恢复。
  • 隐藏下单 / 发布上限：不再按保证金计算购买和发布上限，数量只受挂单库存约束。发布前置条件改为「实名 + 联系方式」。
  • 调整违约处罚：只保留「限制天数 + 降级」，不再扣保证金、不再赔付对方。
  • 隐藏佣金：级别页不展示佣金费率表（运营期免佣）。级别照常按成交笔数累计，每 10 笔升 1 级。
  • 调整平台代交接：流程不变，服务费 ¥100/单改为线下结算，按钮由「支付 ¥100 并申请」改为「提交申请」。

5请业务重点确认

  1. 新用词是否认可：下单 / 待交货 / 交货 / 参考价 / 金价 / 信息服务平台？
  2. 取消保证金后，违约只靠「限制天数 + 降级」约束，是否足够？
  3. 代交接 ¥100 线下结算：由谁收、怎么收、是否开票？
  4. 免佣期间级别只作信用展示，是否仍放在「我的」首页？
